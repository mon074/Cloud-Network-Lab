# Subnet Configuration

## Overview

The next step of the Cloud Network Lab was to create a subnet inside the VPC.

## Configuration

Subnet Name->  Cloud-Network-Lab-Subnet 
VPC-> Cloud-Network-Lab-VPC 
IPv4 CIDR->  10.0.1.0/24
Availability Zone-> ap-south-1b

## Purpose

The subnet provides a smaller network segment within the VPC where AWS resources can be deployed.

## Key Learning

- A subnet is created inside a VPC.
- A subnet uses a portion of the VPC CIDR range.
- Each subnet belongs to a specific Availability Zone.
- Route tables determine how traffic from the subnet is routed.
