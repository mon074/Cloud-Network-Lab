# Cloud Network Lab

## 📌 Project Overview

This project is a hands-on AWS cloud networking lab designed to understand, configure, and troubleshoot fundamental AWS networking components.

The lab focuses on building an isolated network environment and understanding how network traffic flows between AWS resources and the internet.

## 🎯 Objectives

- Understand AWS VPC networking
- Configure IPv4 CIDR blocks
- Create and configure subnets
- Configure route tables
- Configure an Internet Gateway
- Understand internet traffic flow
- Practice cloud network troubleshooting

## 🛠️ AWS Services Used

- Amazon VPC
- Subnets
- Route Tables
- Internet Gateway
